# DSNewLine Connect — релизы

Публичный репозиторий установщиков и автообновлений для **DSNewLine Connect**.

## Скачать

- Последний установщик: [Releases → Latest](https://github.com/Dsnewline/dsn-connect-releases/releases/latest)
- Файл: `DSNewLineConnectSetup-X.Y.Z.exe` (Inno Setup, Windows x64)

## Автообновление

Клиент Connect читает публичный appcast (подпись Ed25519, без GitHub-токена):

- [appcast.xml](https://raw.githubusercontent.com/Dsnewline/dsn-connect-releases/main/appcast.xml)

В этом репозитории **не хранятся** private keys и PAT.

Исходники и документация сборки — в приватном `dsn-connect-app` (`docs/UPDATES.md`).
