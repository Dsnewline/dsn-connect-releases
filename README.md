# DSNewLine Connect

Официальные установщики для Windows (x64).

## Установка

Скачайте последнюю версию:

https://github.com/Dsnewline/dsn-connect-releases/releases/latest

Файл установщика: `DSNewLineConnectSetup-X.Y.Z.exe`

## Обновления

Приложение само проверяет обновления через `appcast.xml`:

https://raw.githubusercontent.com/Dsnewline/dsn-connect-releases/main/appcast.xml

Подпись пакетов — Ed25519. Секреты и исходный код здесь не хранятся.
